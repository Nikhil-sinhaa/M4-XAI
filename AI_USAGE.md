## Phase 1 Usage

### Prompts Used

1. **Prompt**: "Replicate the M4 XAI paper starting with BERT-base"
   - **Output**: Initial BERT training script draft
   - **Modification**: Switched from PaddlePaddle to PyTorch/HuggingFace stack, rewrote training pipeline entirely using custom fine-tuning with gradient accumulation

2. **Prompt**: "Create evaluate_explanations.py that computes MoRF curve for BERT using Captum"
   - **Output**: Initial evaluate script with Integrated Gradients
   - **Modification**: Fixed tokenizer masking strategy, adjusted baseline to use PAD embeddings, corrected token index offset for [CLS]/[SEP]

3. **Prompt**: "Create evaluate_vgg16.py for ImageNet VGG16 MoRF evaluation"
   - **Output**: VGG16 Integrated Gradients evaluation script
   - **Modification**: Added patch-level aggregation into 14×14 grid, corrected masking with zero tensor

4. **Prompt**: "Create table1_resnet50.py to reproduce Table 1 from the M4 paper for ResNet-50"
   - **Output**: Full replication script with exact InterpretDL-matching perturbation formula
   - **Modification**: Verified percentile schedule against InterpretDL source, corrected MoRF score formula to match paper's Equation 1
